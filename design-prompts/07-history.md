# 화면 07. 기록 (History)

완료한 시뮬레이션의 결과와 회고를 돌아보는 화면. 하단 4탭 중 [기록] 탭.

## 레이아웃 (위 → 아래)

1. **헤더**: `기록`

2. **자산 요약 영역** (상단 카드)
   - 현재 총 자산 큰 숫자 (예: `₩1,025,000`)
   - 자산 변화 미니 라인 차트 (완료된 시뮬레이션별 자산 추이)
   - 보조 지표 1줄: `총 12회 연습 · 승률 58% · 평균 +1.2%`

3. **필터 칩** (가로 스크롤): `전체` `단타` `스윙` `장기투자` — 선택형

4. **기록 리스트** — 완료 시뮬레이션 카드, 최신순. 각 카드(접힌 상태):
   ```
   TSLA  단타 · 2026. 7. 28.        +2.5%
   ```
   - 좌측: 종목명(Bold) + 스타일·날짜(회색 캡션)
   - 우측: 수익률 (손익 색상, Bold)

5. **카드 펼침 상태** (탭하면 확장):
   ```
   ₩1,000,000 → ₩1,025,000 · 거래 4회 · 감정 😎 자신감
   ─────────────────────────────
   "EMA 반등 노리고 진입, 계획대로 청산함"   ← 회고 메모
   ```

6. **빈 상태** (기록이 없을 때):
   ```
   아직 완료한 연습이 없어요.
   연습 탭에서 첫 시뮬레이션을 시작해보세요!
   ```

7. **하단 내비게이션 바**: 홈 / 연습 / 기록(활성) / 더보기

## 요청

기록이 4~5개 있는 상태(1개는 펼침, 손실 기록도 1개 포함)와 빈 상태 두 버전을 그려주세요.
