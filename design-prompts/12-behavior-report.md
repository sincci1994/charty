# 화면 12. 행동 리포트 (BehaviorReport)

수익화의 핵심 화면. 화면 10·11에서 수집한 판단·행동 데이터를 **과정 중심 리포트**로 보여준다. 두 화면으로 구성: **A. 세션 리포트**(회고 저장 직후 — 유료 전환의 aha 모먼트)와 **B. 누적 리포트**(기록 탭에서 진입).

## 표현 대원칙 (모든 문장에 적용)

- **심리·성격 단정 금지**: "겁이 많은", "확신이 부족한", "공격적인" 같은 표현 절대 금지.
- 문장 문법은 항상 `[구간/조건] + [횟수·비율·배수] + [관찰된 행동]`. 형용사 없이 관찰만 서술.
  - 좋은 예: `손실 확정 직후 첫 주문 금액이 세션 평균보다 42% 컸습니다`
  - 나쁜 예: `손실 후 충동적으로 베팅이 커지는 성향이에요`
- 수익 보장·실력 향상 약속 표현 금지. 화면 속 수치는 전부 샘플.

## 화면 A. 세션 리포트 (회고 저장 직후)

현행 "회고가 저장되었습니다!" 1.8초 스플래시를 **이 화면이 대체**한다. 자동 이동 없음 — 사용자가 읽고 `홈으로`를 눌러 나간다. 하단 내비 숨김.

위에서 아래로:

1. **확인 라인**: 체크 아이콘 + `회고가 저장되었습니다` (작게 — 주인공이 아님)
2. **결과 1줄** (작은 캡션): `+3.2% · 거래 4회 · 스윙` — 결과는 조연, 과정이 주인공
3. **행동 관찰 카드 2~4개** — 이 세션에서 계산된 것만. 계산 안 되는 지표는 침묵(빈 카드 금지). 샘플 문장:
   - `손실 확정 직후 첫 주문 금액이 세션 평균보다 42% 컸습니다`
   - `수익 포지션은 평균 8캔들, 손실 포지션은 평균 21캔들 보유했습니다`
   - `설정한 손절가 도달 2회 중 1회는 계획대로 실행했습니다`
   - `뉴스 확인 후 대기 중이던 주문을 취소했습니다`
4. **근거 분포 미니 카드** (항상 표시되는 보장 콘텐츠): `기술적 3 · 감정·직관 1` — 이 세션 주문들의 판단 이유 분포
   - `기타`는 자유문이 아니라 **범주로 합산**한다(`기타 2`). 자유문(`note`)은 칩 아래에 인용 줄로 따로 보여준다 — 부분체결로 한 주문이 여러 체결이 되므로 중복은 제거한다
5. ~~**구독 예고 CTA 섹션**~~ — **2026-08-26 노출 중단.** 리포트 구독 기능이 없는 채로 매 세션 권유가 반복되는 것이 신뢰를 깎았다(무거래·관찰 0개인 빈 리포트 위에도 떴다). 기능 출시와 함께 되살린다. 되살릴 때의 원안:
   - 제목: `이런 리포트를 매 세션 받아보세요`
   - 서브: `누적 행동 분석과 맞춤 훈련 추천을 준비하고 있어요`
   - 가격 앵커 (작게): `출시 예정 · 월 ₩4,900` (2026-08-15 가격 표시는 이미 제거)
   - 주 버튼: `미리 신청하기`
   - 보조 (텍스트 링크, 동등하게 누르기 쉽게): `괜찮아요, 홈으로`
   - 되살릴 때 노출 빈도 정책을 함께 정할 것 — '매 세션'은 재현 금지
6. 화면 최하단 `홈으로` 버튼 (CTA 섹션과 무관하게 항상 존재 — 리포트가 회고 저장을 인질로 잡지 않는다)

## 화면 B. 누적 리포트 (기록 탭에서 진입)

기록(07) 화면의 자산 요약 카드 아래에 진입 배너 `내 행동 리포트 →`를 추가하고, 탭하면 이 화면. 하단 내비 유지.

1. **지표 카드 4개** (2×2 그리드 또는 세로 나열):

   | 지표 | 샘플 표현 |
   |---|---|
   | 손절 계획 실행률 | `61%` + `도달 13회 중 8회 계획대로 실행` |
   | 손실 직후 주문 금액 | `+35%` + `손실 직후 첫 주문이 평소보다 커요` |
   | 수익·손실 보유시간 | `2.7배` + `손실 포지션을 그만큼 오래 보유` — **배수로만 표현** (스타일마다 캔들 단위가 달라 절대시간 무의미) |
   | 뉴스 후 판단 변경률 | `62%` + `뉴스 확인 후 기존 결정을 변경한 비율` |

   각 카드 하단에 **근거 캡션 필수**: `최근 12세션 · 손절 입력 거래 9회 기준` — 무엇으로 계산했는지 항상 밝힌다.

2. **지표별 잠금** (전체 잠금이 아님 — 지표마다 열리는 시점이 다르다): 잠긴 카드는 자물쇠 + `손절가를 입력한 거래 10회부터 계산돼요 (현재 3회)` + 진행 바
3. **구버전 안내** (판단 기록 기능 이전의 세션이 있으면 상단에 옅은 배너): `판단 기록 이전의 세션 4개는 분석에서 제외돼요`
4. **하단 티저 행** (구독 예고): `감정별 성과 분석` `맞춤 훈련 추천` — 자물쇠 + `준비 중` 배지

## 요청

세 버전을 그려주세요 (각 라이트/다크):

1. **A 정상** — 관찰 카드 3개 + 근거 분포 (CTA 섹션은 현재 미노출)
2. **B 부분 잠금** — 지표 4개 중 3개 열림, 1개(손절 실행률) 잠김 + 구버전 배너
3. **B 전체 잠금** — `분석할 세션이 아직 부족해요 · 3세션 완료 후 열려요 (1/3)` + 진행 바 + 티저 행

규격·토큰·테마는 `00-common.md` 기준. 이 화면은 세션 종료 후라 블라인드 제약 없음(실제 날짜 표기 가능).
