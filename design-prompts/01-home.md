# 화면 01. 홈 (Home)

앱의 메인 대시보드. 사용자를 맞이하고, 성과를 요약하고, 연습으로 진입시키는 허브. 하단 4탭 중 [홈] 탭.

## 레이아웃 (위 → 아래)

1. **인사 영역**
   - 인사말: `👋 안녕하세요, USER님!` (20px Bold)
   - 격려 메시지: `🔥 7일 연속 연습 중! 대단해요!` (16px Medium) — 연속 연습 일수에 따라 동적 ("X일 연속 연습 중입니다")

2. **주 CTA 버튼**: `🚀 연습하러 가기` — 풀 너비 Primary 버튼 (높이 48px)

3. **성과 요약 섹션** — 제목 `📊 성과 요약`
   - 가로 3개 카드: 수익률 / 승률 / 총 거래 수
     - 표기 예: `+12.5%` `65%` `47건` (큰 숫자 24px Bold + 라벨 14px)
   - **수익률 카드만** 배경색 변화: 양수=초록 톤 / 음수=빨강 톤 / 0=회색. 나머지 두 카드는 중성 색.
   - 카드 아래 Secondary 버튼 2개: `[자산 현황]` `[상세 분석]` (→ 기록 탭으로 이동)

4. **연습 계속하기 카드** — 제목 `📊 연습 계속하기`. 두 가지 상태:

   **A. 진행중인 연습이 없을 때**
   ```
   아직 시작된 시뮬레이션이 없어요.
   지금 첫 연습을 시작하고 나만의
   투자 패턴을 만들어보세요!
              [Start New]
   ```

   **B. 진행중인 연습이 있을 때**
   ```
   현재 스윙 진행 중
   |████████████       | 78%
     [Continue]   [Start New]
   ```
   - `현재 {트레이딩 스타일명} 진행 중` + 진행률 바 + 퍼센트
   - [Continue] = Primary, [Start New] = Secondary

5. **하단 내비게이션 바**: 홈(활성) / 연습 / 기록 / 더보기

## 상태 분기

- 신규 사용자: 성과 카드 모두 0 또는 `-` + A 상태 카드
- [Start New]를 진행중 상태에서 누르면 기존 시뮬을 버리고 새로 시작 (확인 다이얼로그 전제)

두 상태(A/B)를 모두 보여주는 버전으로 그려주세요.
