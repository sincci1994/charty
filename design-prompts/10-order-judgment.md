# 화면 10. 주문 판단 기록 (OrderSheet_Judgment)

시뮬레이션(05)의 주문 바텀시트 확장. 목적은 **주문 순간의 판단(이유·확신도·리스크 계획)을 구조화해 수집**하는 것 — 이 데이터가 나중에 행동 리포트(화면 12)의 원천이 된다. 주문 흐름이 무거워지면 안 되므로, 추가 입력은 탭 몇 번으로 끝나는 수준을 유지한다.

레이아웃 세부는 자유롭게 제안해주세요. 아래는 콘텐츠·정책과 유지할 프레임만 정의합니다. 화면 속 수치는 전부 샘플입니다.

## 유지되는 프레임 (현행 주문 시트)

위에서 아래로, 기존 구조 그대로:

1. 시트 드래그 핸들
2. 헤더: `Long`(초록) 또는 `Short`(빨강) + `지정가 주문` 캡션, 우측에 `[Open][Close]` 세그먼트
3. `Limit Price` 라벨 + 스테퍼(− / 가격 입력 / +) + `현재가` 버튼
4. `Quantity` 라벨(우측에 `주문 가능 ₩X` 힌트) + `[25%][50%][75%][Max]` 칩 + 직접 입력
5. 풀 너비 CTA (`Open Long` / `Close Short` 등)

**신규 블록은 4(수량)와 5(CTA) 사이에 들어간다.** 콘텐츠가 늘어나므로 시트 내부 스크롤(max-height ~85vh)을 허용해주세요.

## 추가 블록

### (a) 판단 이유 — `왜 이 주문인가요?`

- 칩 5개, **복수 선택 가능**: `기술적` `기업·실적` `거시경제` `뉴스·분위기` `감정·직관`
- 보조 문구(캡션): `감정도 기록할 가치가 있는 근거예요` — 감정·직관 칩이 부정적으로 보이면 안 됨. 5개 칩은 전부 동등한 톤.
- 자유입력 텍스트는 없음 (세션 종료 후 회고 메모가 따로 있음)

### (b) 확신도

- 라벨 `확신도` + 1~5 세그먼트(탭 선택), 양끝에 캡션 `낮음` / `높음`

### (c) 리스크 설정 (선택) — 접힌 폴드

- 접힌 상태: `리스크 설정 (선택)` 한 줄 + 펼침 화살표
- 펼치면:
  - `손절가`: 퀵 칩 `[-3%][-5%][-10%]` + 직접 입력. 칩 선택 시 환산 가격 표시 (예: `-5% → ₩11,400`)
  - `목표가`: 퀵 칩 `[+5%][+10%][+20%]` + 직접 입력, 동일 문법
- 캡션: `자동 체결되지 않아요. 계획과 실제 실행의 차이를 기록하기 위한 값이에요`

## 정책 (상태 분기)

- **이유 1개 이상 + 확신도는 필수** — 미입력 시 CTA 비활성 (수량·가격 조건과 동일하게).
- **손절가·목표가는 선택** — 비워두고 제출 가능.
- **Close 모드에서도 이유·확신도는 그대로 노출** (청산 판단도 기록 대상 — "불안해서 매도"가 대표적). 리스크 설정 폴드만 숨김.

## 요청

세 버전을 그려주세요 (각 라이트/다크):

1. **Open 기본** — 이유·확신도 미입력(CTA 비활성), 리스크 폴드 접힘
2. **Open 입력 완료** — 칩 2개 선택(`기술적`+`감정·직관`), 확신도 3, 리스크 폴드 펼침 + 손절 -5% 선택된 상태
3. **Close 변형** — 이유·확신도만 있는 짧은 시트

규격·토큰·테마는 `00-common.md` 기준.
