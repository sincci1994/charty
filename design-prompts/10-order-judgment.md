# 화면 10. 주문 판단 기록 (OrderSheet_Judgment)

시뮬레이션(05)의 주문 바텀시트. **현물 문법** — 트레이드 바의 `매수`/`매도` 버튼으로 진입하며, 매수는 사기·매도는 보유분 팔기(상한 = 보유수량)다. 선물식 Long/Short·Open/Close 개념은 쓰지 않는다.

목적은 **주문 순간의 판단(이유·리스크 계획)을 구조화해 수집**하는 것 — 이 데이터가 행동 리포트(화면 12)의 원천이 된다. 추가 마찰은 정확히 **탭 1회(이유 칩)**를 넘지 않는다.

레이아웃 세부는 자유롭게 제안해주세요. 아래는 콘텐츠·정책만 정의합니다. 수치는 전부 샘플입니다.

## 시트 구조 (위 → 아래)

1. 시트 드래그 핸들
2. 헤더: `매수`(수익색 계열) 또는 `매도`(손실색 계열) + `지정가 주문` 캡션 — **모드 전환 세그먼트 없음** (트레이드 바에서 이미 선택하고 들어옴)
3. `지정가` 라벨 + 스테퍼(− / 가격 입력 / +) + `현재가` 버튼
4. `수량` 라벨 + `[25%][50%][75%][Max]` 칩 + 직접 입력
   - 매수: 우측 힌트 `주문 가능 ₩X`
   - 매도: 우측 힌트 `매도 가능 N주`
5. **판단 이유** — `왜 이 주문인가요?`
   - 칩 5개, **복수 선택 가능**: `기술적` `기업·실적` `거시경제` `뉴스·분위기` `감정·직관`
   - 보조 캡션: `감정도 기록할 가치가 있는 근거예요` — 5개 칩은 전부 동등한 톤 (감정·직관이 부정적으로 보이면 안 됨)
   - 자유입력 텍스트 없음 (세션 종료 후 회고 메모가 따로 있음)
6. **리스크 설정 (선택)** — 접힌 폴드, **매수 시트에만** (매도는 청산이라 없음)
   - 펼치면 `손절가`: 퀵 칩 `[-3%][-5%][-10%]` + 직접 입력, 칩 선택 시 환산 가격 표시 (예: `-5% → ₩11,400`)
   - `목표가`: 퀵 칩 `[+5%][+10%][+20%]` + 직접 입력, 동일 문법
   - 캡션: `자동 체결되지 않아요. 계획과 실제 실행의 차이를 기록하기 위한 값이에요`
7. 풀 너비 CTA: `매수하기` / `매도하기`

콘텐츠가 늘어나므로 시트 내부 스크롤(max-height ~85vh)을 허용해주세요.

## 정책 (상태 분기)

- **이유 칩 1개 이상 필수** — 미선택 시 CTA 비활성 (수량·가격 조건과 동일). 이것 외의 추가 필수 입력은 없다.
- **손절가·목표가는 선택** — 비워두고 제출 가능.
- **매도 시트에도 이유 칩은 그대로** (매도 판단이 핵심 데이터 — "불안해서 매도", "목표 도달" 등). 리스크 폴드만 없음.

## 요청

세 버전을 그려주세요 (각 라이트/다크):

1. **매수 기본** — 칩 미선택(CTA 비활성), 리스크 폴드 접힘
2. **매수 입력 완료** — 칩 2개 선택(`기술적`+`감정·직관`), 리스크 폴드 펼침 + 손절 -5% 선택된 상태
3. **매도** — 이유 칩만 있는 짧은 시트, `매도 가능 12주` 힌트

규격·토큰·테마는 `00-common.md` 기준.
