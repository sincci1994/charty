# 화면 04. 커스텀 트레이딩 스타일 (CustomTradingStyle)

나만의 거래 기간/캔들 간격 조합을 만들거나 편집하는 화면. 트레이딩 스타일 선택 화면의 [+] 또는 [설정]으로 진입.

## 레이아웃 (위 → 아래)

1. **헤더**
   - 제목: `⚙️ 커스텀 트레이딩 스타일`
   - 우측 상단: `[Delete]` (빨간 텍스트 버튼 — 편집 모드에서만 표시, 삭제 후 이전 화면 복귀)

2. **입력 필드 1**
   - 라벨: `Custom Trading Name:`
   - 텍스트 입력 (placeholder: `이름을 입력하세요`)

3. **입력 필드 2**
   - 라벨: `Trading Period:`
   - 숫자 입력 + 보조 안내 `(1~365일)`

4. **선택 그룹**
   - 라벨: `Candle Timeframe:`
   - 칩/라디오 7개 (2줄 배치): `5분` `15분` `30분` `1시간` `4시간` `1일` `1주`
   - 선택된 칩 강조

5. **하단 CTA**: `[Set]` — 풀 너비 Primary
   - **이름·기간·타임프레임이 모두 입력됐을 때만 활성화**

## 상태 분기

- 신규 생성 모드([Delete] 없음, 필드 비어있고 [Set] 비활성)와 편집 모드([Delete] 있음, 값 채워짐, [Set] 활성) 두 버전을 보여주세요.
