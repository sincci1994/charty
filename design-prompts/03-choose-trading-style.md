# 화면 03. 트레이딩 스타일 선택 (ChooseTradingStyle)

시뮬레이션 시작 전, 거래 기간과 캔들 간격을 결정하는 트레이딩 스타일을 고르는 화면. 연습 모드 선택 → 이 화면 → 시뮬레이션.

## 레이아웃 (위 → 아래)

1. **헤더**
   - 제목: `📊 트레이딩 스타일 선택`
   - 안내문 (작은 회색 텍스트): `"투자 기간은 해당 기간 내 거래 종료를 목표로 하며, 시간 단위는 트레이딩 시 사용할 캔들의 시간 단위를 의미합니다"`

2. **섹션 라벨**: `기본 트레이딩 스타일:`

3. **기본 스타일 카드 3개** (선택형 — 탭하면 선택 상태 표시)
   ```
   🔥 단타
   거래 기간 1일 / 차트 간격 5분
   ```
   ```
   📈 스윙
   거래 기간 14일 / 차트 간격 1시간
   ```
   ```
   💎 장기투자
   거래 기간 60일 / 차트 간격 4시간
   ```
   - 선택된 카드는 보더/배경 강조

4. **섹션 라벨**: `커스텀 스타일:`

5. **커스텀 스타일 슬롯**
   - 저장된 커스텀 스타일이 있으면 카드로 표시:
     ```
     {커스텀 스타일 이름}
     {거래 기간} / {차트 간격}        [설정]
     ```
     [설정] → 커스텀 스타일 편집 화면
   - 새로 추가 버튼: `[+]` (점선 보더의 빈 카드 형태 권장) → 커스텀 스타일 생성 화면

6. **하단 CTA**: `[Start Simulation]` — 풀 너비 Primary
   - **스타일을 선택했을 때만 활성화**. 미선택 시 비활성(흐림) 상태.

## 상태 분기

- 미선택 상태(버튼 비활성)와 선택 상태(카드 강조 + 버튼 활성) 두 버전을 보여주세요.
