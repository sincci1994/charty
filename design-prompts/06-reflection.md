# 화면 06. 회고 작성 (Reflection) + 완료 스플래시 (ReflectionSplash)

시뮬레이션 종료 직후 결과를 확인하고 감정·회고를 기록하는 화면. 작성 완료 시 짧은 스플래시를 거쳐 홈으로 돌아간다. 하단 내비게이션 바는 숨긴다.

## 화면 A. 회고 작성

### 레이아웃 (위 → 아래)

1. **헤더**: `📝 회고 작성`

2. **결과 요약 카드** (이 시점에 종목명 공개)
   ```
   TSLA 연습 결과 · 단타
   +2.5%              ← 큰 숫자 (28px Bold, 손익 색상)
   ₩1,000,000 → ₩1,025,000 · 거래 4회
   ```

3. **감정 선택 섹션**
   - 질문: `이 거래를 진행하면서 어떤 기분이 들었나요?`
   - 선택 칩 5개 (단일 선택): `😰 불안함` `😬 긴장됨` `😎 자신감` `😢 우울함` `😐 무덤덤함`
   - 선택된 칩은 액센트 색으로 강조

4. **회고 텍스트 섹션**
   - 라벨: `매매 기록을 작성해주세요:`
   - 여러 줄 텍스트영역 (5줄 내외, placeholder: `왜 그렇게 매매했나요? 잘한 점과 아쉬운 점을 기록해보세요.`)
   - 우측 하단 글자수 카운터: `(0/500자)`

5. **하단 CTA**: `[Complete Reflection]` — 풀 너비 Primary. 감정 선택 전에는 비활성.

## 화면 B. 완료 스플래시

전체 화면 중앙 정렬, 미니멀:

```
        ✅
회고가 저장되었습니다!

  잠시 후 홈으로
  자동 이동됩니다
```

- 체크 아이콘에 가벼운 등장 애니메이션, 2초 후 자동으로 홈 이동

## 요청

화면 A(감정 하나 선택된 상태)와 화면 B를 모두 그려주세요.
