# 화면 09. 시뮬레이션 News 탭 (TradeSimulation_News)

시뮬레이션 화면(05)의 `[Chart] / [News]` 탭 중 News 탭. 목적은 **뉴스 피드가 아니라 시장 심리 대시보드** — 시뮬 시점 기준으로 "지금 시장이 어떤 국면인가"를 경제지표로 읽는 화면이다. 트레이더가 차트를 보다가 넘어와 10초 안에 거시 분위기를 파악하고 돌아가는 흐름.

레이아웃·구성은 자유롭게 제안해주세요. 아래는 콘텐츠와 제약만 정의합니다.

## 유지되는 프레임 (05와 공통)

- 상단 탭바 `[Chart] / [News]` (News 활성), 좌측 ← Back
- 진행률 영역, 종목 숨김 표시(`****** (숨김)`)
- 하단 고정 트레이드 바 (Assets/현재가 + Long/Short) — News를 보면서도 주문 가능
- **Chart 전용 요소는 News에서 숨김**: 타임프레임 칩(5m~1w), 보조지표 토글(EMA/BOL/RSI/VOL)
- `[다음 캔들 ▶]` 버튼은 News에서도 유지 (지표를 보며 시간 진행 가능)

## 콘텐츠 (실데이터 준비됨 — econ.json)

각 지표는 `[발표시점, 값]` 시계열이며, **시뮬 현재 시각 이전 발표분만** 노출된다. 시간이 진행되면 새 발표가 나타난다.

| 그룹 | 지표 | 단위 | 성격 |
|---|---|---|---|
| 금리 | 기준금리(실효) | % | 월말 스냅샷. FOMC 방향성의 결과 |
| 물가 | CPI 전년비 / PCE 물가 전년비 / PPI 전년비 | % | 물가 3형제 — 함께 보여줄 때 가치 (PPI→CPI→PCE 파급) |
| 고용 | 실업률 / 비농업 고용 증감 | % / 천 명 | 노동시장 온도 |
| 유동성 | M2 증가율(전년비) | % | 돈이 풀리는가 조이는가 |
| 심리 | VIX 변동성지수 | (지수) | 주간 시계열, 공포 게이지. 스파이크가 정보 |
| (추후) | FOMC 금리 전망(점도표 중간값) | % | 데이터 연동 전 — 디자인에는 자리를 잡아주세요 |

## 꼭 담아야 할 것

1. **그래프 중심**: 값 나열이 아니라 **추이 그래프**로. 각 지표의 과거 이력(시뮬 시점까지)을 스파크라인/미니 라인차트로. 탭하면 크게 보는 상세도 환영.
2. **이전값 → 발표값**: 최근 발표의 변화 방향(▲▼)이 한눈에.
3. **물가 3종(CPI·PCE·PPI)은 비교 가능하게** — 한 그래프에 겹치거나 나란히.
4. **VIX는 심리 게이지로** — 수치+구간 해석(안정/불안/공포 같은 시각적 온도) 표현 자유.
5. **FOMC 금리 계획 섹션** — 현재 기준금리와 향후 전망 경로를 보여줄 자리. 지금은 플레이스홀더여도 됨.

## 블라인드 제약 (중요)

- **절대 날짜·연도 표기 금지**. 축 라벨도 실제 날짜 대신 상대 표기(`-2년`, `-6개월`, `최근`)를 사용.
- 시대를 특정할 수 있는 사건명·인물명·뉴스 헤드라인 없음. 수치와 방향만.
- 화면 어딘가에 짧은 안내: `시점 추정을 막기 위해 날짜는 표시하지 않아요`
