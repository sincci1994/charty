# 화면 02. 연습 모드 선택 (PracticeMain)

연습 방식을 고르는 화면. 하단 4탭 중 [연습] 탭. 현재 선택 가능한 모드는 시뮬레이션 하나, 스피드 퀴즈는 준비중.

## 레이아웃 (위 → 아래)

1. **헤더**
   - 제목: `🎮 연습 모드 선택`
   - 서브 카피: `"원하는 연습 방식으로 시작해보세요!"`

2. **Simulation Mode 카드** (활성, 탭 가능)
   ```
   🧪 Simulation Mode
   실제 차트를 보고 매매 연습
   📈 지정가 / 감정 / 이유 기록 포함
   ✅ 실전감 + 회고 훈련
          [지금 시작하기 >]
   ```
   - 설명 보조 문구: `캔들을 하나씩 직접 생성하며 흐름을 예측하고 매매 판단`
   - 카드 전체가 강조된 스타일 (Primary 느낌), 버튼 [지금 시작하기 >]

3. **Speed Quiz 카드** (비활성, 준비중 — 흐리게/디밍 처리)
   ```
   ⚡ Speed Quiz (준비중)
   빠른 판단 훈련용 퀴즈
   📊 감정/이유 버튼식 선택
   🕒 5분 완성 / 즉시 피드백
        [개발 중입니다 🔧]
   ```
   - 버튼은 비활성 스타일, 탭 불가 느낌

4. **하단 내비게이션 바**: 홈 / 연습(활성) / 기록 / 더보기

## 디자인 원칙

- 카드형: 어떤 모드인지 직관적으로 비교 가능하게, 향후 모드 추가 시 카드만 추가되는 구조
- 활성 카드와 준비중 카드의 시각적 위계 차이를 분명하게
