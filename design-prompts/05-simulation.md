# 화면 05. 트레이딩 시뮬레이션 (TradeSimulation_Chart) — 핵심 화면

> **2026-08 현행화**: 현물 전환 방침으로 트레이드 바의 `Long/Short`는 `매수/매도`로, 주문의 Open/Close 개념은 폐기됩니다(숏 없음 — Future 모드 별도 검토). 주문 시트는 [10번](./10-order-judgment.md)이 최신 스펙. 이 문서의 해당 서술은 당시 발주서 기록으로 남깁니다.

과거 차트의 캔들을 [다음 캔들] 버튼으로 하나씩 공개하며 지정가 매매를 훈련하는, 앱에서 가장 중요한 화면. 세로로 길어 스크롤되는 화면이며, 상단 ~2/3는 차트 위젯, 하단 ~1/3은 트레이딩 패널이다. 하단 내비게이션 바는 숨긴다.

## 레이아웃 (위 → 아래)

1. **상단 탭바**: `[Chart] / [News]` — 각 50% 폭, 활성 탭 하단 2px 보더 강조. 기본 Chart 활성. **News 탭은 "준비중" 배지**를 달고 비활성 처리.
   - 좌측에 `← Back` 아이콘.

2. **진행률 영역** (높이 ~60px, 2줄)
   - 진행률 바: 5블록 세그먼트 형태 `[■■■□□]` 또는 연속 바 + 퍼센트 텍스트 (14px)
   - 상태 메시지 (12px, 진행률 구간별로 변화):

   | 진행률 | 메시지 |
   |---|---|
   | 0–59% | `차트 분석을 계속해보세요` |
   | 60–79% | `거의 다 왔어요!` |
   | 80–99% | `마지막 캔들입니다` |
   | 100% | `모든 캔들이 생성되었습니다!` + **깜빡이는 `[지금 회고 작성하기 >]` 버튼** (1.5초 주기 펄스) |

3. **종목/스타일 표시**: 종목명은 시뮬레이션 중 **숨김 처리 `****** (숨김)`** (선입견 방지, 종료 후 공개). 옆에 스타일·타임프레임 (예: `단타 · 5분`).

4. **타임프레임 토글**: 알약형 칩 가로 나열 `5m` `15m` `1h` `4h` `1d` — 활성 칩은 채움색, 비활성은 연한 배경 (현재 시뮬의 타임프레임만 활성, 나머지 비활성).

5. **캔들 차트 영역** (폭 358px, 높이 ~290px)
   - 캔들스틱 차트 + EMA 13·25·200 라인 오버레이 (서로 다른 색 3선)
   - 그 아래 거래량 바 영역 (~60px)

6. **인디케이터 토글 + 진행 버튼 행**
   - 좌측: 토글 칩 `EMA` `BOL` `RSI` `VOL` (ON=채움/OFF=연함, 즉시 차트 반영)
   - 우측: **`[다음 캔들 ▶]` 버튼** (아웃라인, 115×38) — 진행률 100%에선 사라지고 진행률 영역의 회고 버튼이 CTA가 됨

7. **자산 카드** (흰/다크 카드, 1줄): 좌 `Assets: ₩1,000,000` / 우 `PnL: +₩25,000 (+2.5%)` — 손익 색상 규칙 적용

8. **트레이딩 패널 카드** — 상단 3탭: `[Order] [Position] [Open Orders]` (활성 탭 하단 2px 보더)

   **Order 탭**
   - `[Open] / [Close]` 세그먼트 컨트롤 (알약형)
   - `Direction` 라벨 + `[Long]` `[Short]` 버튼 2개 (Long=초록 계열, Short=빨강 계열, 선택 시 강조)
   - `Quantity` 라벨 + 숫자 입력 (placeholder `Enter quantity`)
   - `Limit Price` 라벨 + 숫자 입력 (placeholder `Enter limit price`) + 우측 `[현재가]` 작은 버튼
   - `매매 이유 (선택)` 라벨 + **빠른 선택 버튼 칩들**: `지지선 반등` `저항 돌파` `추세 추종` `손절` `수익 실현` `과매도 반등` + 자유 입력 텍스트영역 (placeholder `왜 이 판단을 했나요?`)
   - `[Place Order]` 풀 너비 Primary 버튼

   **Position 탭**
   - LONG/SHORT 포지션 카드 0~2개. 각 카드:
     ```
     LONG Position
     • Qty  : 15주
     • Avg  : ₩148,670
     • Price: ₩150,250
     • PnL  : +₩23,700 (+1.6%)
     Entry History ▾   (접힘/펼침 — 예: 10주 @ ₩148,000 / 5주 @ ₩150,000)
     ```
   - 없으면 빈 상태: `보유 포지션 없음`

   **Open Orders 탭**
   - 미체결 목록: 방향, 수량, 지정가, 상태, 우측 ❌ 취소 버튼
   - 없으면 빈 상태: `📭 미체결 주문 없음`

9. **하단 보조 버튼 행**: `[End Now]` `[Chart Setting]` `[Hint]` — 작은 고스트 버튼 3개. Chart Setting과 Hint는 **준비중 배지**. [End Now]는 조기 종료(확인 다이얼로그 → 잔여 포지션 종가 청산 → 회고).

## 상태 분기 (두 버전으로 그려주세요)

- **진행 중 (예: 60%)**: 진행률 바 부분 채움 + "거의 다 왔어요!", [다음 캔들 ▶] 활성, Order 탭 열림
- **완료 (100%)**: 진행률 바 가득 + "모든 캔들이 생성되었습니다!" + 깜빡이는 회고 버튼, Position 탭 열림 (보유 포지션 카드 표시)

## 인터랙션 노트

- [다음 캔들] 클릭 → 새 캔들 1개 공개 + 지정가 체결 검사 + 진행률 증가 (블록 채움 애니메이션 0.3s)
- 100% 도달 시 완료 글로우 애니메이션 + 회고 버튼 펄스 (1.5s 무한)
- 포지션 보유 중 [End Now] → 확인 다이얼로그 `"강제 청산됩니다. 진행할까요?"`
