# 화면 08. 더보기 (More)

앱 정보와 데이터 관리를 담당하는 보조 화면. 하단 4탭 중 [더보기] 탭. 계정/로그인이 없는 로컬 앱이므로 항목이 적다.

## 레이아웃 (위 → 아래)

1. **헤더**: `더보기`

2. **앱 소개 카드**
   ```
   차티 (베타)
   과거 캔들을 하나씩 넘기며 매매 습관을
   훈련하는 모의투자 앱입니다.
   모든 데이터는 이 브라우저에만 저장됩니다.
   ```

3. **설정 리스트** (셀 형태, 우측 화살표 or 토글)
   - `🎨 화면 테마` — 라이트/다크 (준비중 배지 가능)
   - `📖 사용법 가이드` (준비중 배지)

4. **데이터 관리 섹션**
   - `전체 데이터 초기화` — **빨간 텍스트** 셀. 탭 시 확인 다이얼로그 `"모든 기록과 자산을 초기화할까요? 되돌릴 수 없습니다."`

5. **앱 정보 푸터**: 버전 표기 (예: `v0.1.0`) — 작은 회색 텍스트, 중앙 정렬

6. **하단 내비게이션 바**: 홈 / 연습 / 기록 / 더보기(활성)

## 요청

기본 상태 + 초기화 확인 다이얼로그가 뜬 상태 두 버전을 그려주세요.
