# 13. 캐릭터 부(富) 단계 이미지 (Avatar Wealth Tiers)

홈 자산 카드와 스피드 게임 화면의 캐릭터를 '거지 → 펜트하우스' 사다리로 확장하기 위한 **이미지 생성 요청서**다.
화면 브리프가 아니라 에셋 요청서라 `00-common.md`와 함께 붙여넣지 않는다. 원본 12장(`avatar_images/`)은 ChatGPT 이미지 생성(gpt-image)으로 만들었으므로 같은 도구에 아래 프롬프트를 쓴다.

> 2026-10-20 작성. 금액·단계 이름은 임시값이다 — 기준은 코드의 `WEALTH_TIERS`(`charty-web/src/lib/data.ts`)이고, 이 문서와 어긋나면 코드가 맞다.

## 부 단계 사다리

| # | 단계 | 총자산 | 이미지 키 | 상태 |
|---|---|---|---|---|
| 0 | 거지 | 300만 미만 | `beggar` | **새로** |
| 1 | 빈털터리 | 300만~ | `00` | 기존 |
| 2 | 개미 | 800만~ (시작 1천만) | `01` | 기존 |
| 3 | 목돈 | 1,300만~ | `02` | 기존 |
| 4 | 첫 차 | 2,000만~ | `car` | **새로** |
| 5 | 명품 | 4,000만~ | `luxury` | **새로** |
| 6 | 사장님 | 8,000만~ | `boss` | **새로** |
| 7 | 슈퍼카 | 1.5억~ | `supercar` | **새로** |
| 8 | 건물주 | 3억~ | `landlord` | **새로** |
| 9 | 펜트하우스 | 10억~ | `rich` | 기존 |

- 새로 만들 그림은 6단계 × 3나이(학생·어른·노년) = **18장**이다.
- 그림이 오기 전에는 가장 가까운 기존 그림(`00`·`02`)이 대신 보이고, 단계 이름과 게이지는 이미 새 사다리를 따른다.
- 우선순위는 학생 → 어른 → 노년이다. 프로필에 연령대가 없는 사용자는 기본 25세라 학생 그림을 본다.

## 공통 규칙

- **참고 이미지**: 같은 나이의 `avatar_images/{child|young|old}_01.png`를 함께 첨부한다 (캐릭터 일관성).
- **캐릭터**: 파란색→보라색 그라데이션의 광택 있는 3D 젤리 캐릭터, 하얀 타원형 배, 분홍 볼, 큰 갈색 눈, 짧은 팔다리.
  - 학생(child): 옷 없음
  - 어른(young): 흰 셔츠 + 파란 넥타이, 가슴 주머니에 펜
  - 노년(old): 흰 눈썹·흰 수염, 나무 지팡이
- 기존 그림과 같은 3D 렌더와 조명, 정면 전신, 화면 가운데, 캐릭터 크기도 비슷하게.
- **배경 투명 PNG, 정사각형 1:1.** 펜트하우스만 배경 있는 장면이고, 새 6단계는 모두 투명이다.
- 글자, 숫자, 실제 브랜드 로고는 넣지 않는다.
- 홈에서 92px, 스피드 화면에서 56px로 작게 보이므로 소품은 1~2개만, 실루엣으로 알아볼 수 있게 크게.
- 파일명 `{나이}_{키}.png` (예: `young_car.png`), 저장 위치 레포 루트 `avatar_images/` (gitignore — 원본은 로컬 보관).

## 프롬프트 틀 (참고 이미지와 함께 붙여넣기)

```
첨부한 캐릭터를 그대로 유지해서 새 그림을 그려 주세요.
캐릭터: 파란색에서 보라색으로 넘어가는 광택 있는 3D 젤리 캐릭터, 하얀 타원형 배, 분홍 볼,
크고 반짝이는 갈색 눈, 짧고 통통한 팔다리. {나이 특징}
스타일: 첨부 이미지와 같은 3D 렌더와 조명, 정면 전신, 화면 가운데, 캐릭터 크기도 비슷하게.
배경: 완전히 투명한 PNG. 비율: 정사각형 1:1.
글자, 숫자, 실제 브랜드 로고는 넣지 마세요.
장면: {장면}
```

`{나이 특징}`에는 공통 규칙의 나이별 특징을, `{장면}`에는 아래 표의 칸을 넣는다.

## 단계별 장면

| 키 | 학생 (child) | 어른 (young) | 노년 (old) |
|---|---|---|---|
| `beggar` 거지 | 깨진 돼지저금통 앞에 주저앉아 울먹이며 해진 담요를 두름 | 해진 셔츠에 넥타이가 풀린 채 골판지 위에 앉아 빈 깡통을 앞에 둠 | 신문지를 덮고 바닥에 앉아 빈 깡통을 앞에 둠, 지팡이는 옆에 |
| `car` 첫 차 | 새 자전거 옆에서 헬멧 쓰고 브이 | 작고 귀여운 경차 옆에서 자동차 키를 들고 활짝 웃음 | 반짝이는 작은 클래식 세단 옆에서 지팡이를 짚고 흐뭇 |
| `luxury` 명품 | 새 게임기와 운동화 상자를 품에 안고 신남 | 양손에 쇼핑백 여러 개, 손목에 금시계, 머리에 선글라스 | 금시계를 차고 골프백 옆에 섬, 고급 중절모 |
| `boss` 사장님 | 작은 음료 가판대 뒤에서 사장님 포즈, 동전통 | 큰 책상 뒤 가죽 의자에 앉아 팔짱, 책상에 명패(글자 없음)와 커피 | 동네 가게 계산대 뒤에서 흐뭇하게 웃음 |
| `supercar` 슈퍼카 | 빨간 레이싱 카트에 타서 고글을 씀 | 빨간 슈퍼카에 기대 선글라스를 끼고 엄지척 | 검은 리무진 뒷문 앞에서 지팡이를 짚음 |
| `landlord` 건물주 | 꼬마빌딩 앞에서 열쇠 꾸러미를 흔듦 | 4~5층 빌딩 앞에서 커다란 열쇠 꾸러미를 자랑 | 빌딩 앞 흔들의자에 앉아 열쇠 꾸러미를 듦 |

- 거지는 기존 빈털터리(`00`, 반창고·보따리)보다 한 단계 더 비참하되, 우울하지 않고 코믹하게.
- 선택(여유 있으면): 10단계 재벌(50억~, `tycoon`) — 학생은 개인 섬 해먹, 어른은 전용기 앞 레드카펫, 노년은 요트 갑판. 만들면 사다리에 한 줄만 더하면 된다.

## 받은 뒤 처리

1. 원본을 `avatar_images/`에 넣는다.
2. 256px 팔레트 PNG로 줄여 `charty-web/public/avatar/`에 넣는다 (기존 배포본과 같은 규격, 장당 13~35KB):
   ```
   python -I -c "import sys; from PIL import Image; im = Image.open(sys.argv[1]).convert('RGBA').resize((256, 256), Image.LANCZOS); im.quantize(256, method=Image.Quantize.FASTOCTREE).save(sys.argv[2], optimize=True)" avatar_images/young_car.png charty-web/public/avatar/young_car.png
   ```
3. **학생·어른·노년 세 장이 모두 `public/avatar/`에 있는 단계만** `WEALTH_TIERS`의 `img`를 새 키로 바꾼다(예: `'02'` → `'car'`). 런타임 존재 검사가 없어서, 한 장이라도 빠진 채 키를 바꾸면 그 나이 사용자의 캐릭터가 깨진 이미지가 된다. 그다음 `data.test.ts`의 `avatarSrc` 기대값을 맞춘다(10단계를 늘리면 표 불변식 테스트의 개수도).
