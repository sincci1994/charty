# 차티(Charty) 공통 디자인 컨텍스트

> **사용법**: 클로드 디자인에 화면을 요청할 때, 이 문서 + 원하는 화면의 .md 파일(01~12)을 함께 붙여넣으세요.

## 앱 소개

차티(Charty)는 **과거 차트의 캔들을 하나씩 직접 넘기며([다음 캔들]) 매매 판단을 훈련하는 모의투자 앱**이다. 실시간 시세가 아니라 과거 데이터로 다양한 시장 상황을 빠르게 반복 경험하고, 매매 후 감정과 회고를 기록해 자신의 매매 습관을 객관화하는 것이 목적이다. 수익보다 **손절 타이밍과 생존율**을 중시한다. 타겟은 초보 투자자와 감정매매를 극복하려는 사람.

## 화면 플로우 전체

```
홈 ─┬─ [연습하러 가기 / Start New] → 연습 모드 선택 → 트레이딩 스타일 선택 ─→ 시뮬레이션
    │                                                   └ [+/설정] → 커스텀 스타일 편집
    ├─ [Continue] ──────────────────────────────────────────────────→ 시뮬레이션 (이어하기)
    └─ 하단 탭: 홈 / 연습 / 기록 / 더보기

시뮬레이션 → (진행률 100% 또는 [End Now]) → 회고 작성 → 완료 스플래시 → 홈
```

## 공통 규격

- **뷰포트**: 모바일 390px 폭 기준 (iPhone). 세로 스크롤 허용.
- **하단 내비게이션 바** (모든 탭 화면에 고정): 홈 / 연습 / 기록 / 더보기 — 아이콘 + 라벨, 활성 탭 강조. 시뮬레이션·회고 화면에서는 숨김 가능.
- **언어**: 한국어 UI. 문서에 적힌 문구를 그대로 사용.
- **통화**: 원화. 시작 자산 ₩1,000,000. 숫자는 천 단위 콤마.
- **손익 색상**: 수익 = 초록(#4CAF50 계열), 손실 = 빨강(#F44336 계열), 0/중립 = 회색.

## 디자인 토큰

**공통**
- 카드 라운드 12px, 버튼 라운드 10px·높이 48px, 미묘한 그림자 `0 2px 4px rgba(0,0,0,0.08)`
- 타이포: sans-serif (Pretendard/SF Pro 계열). 화면 제목 20px Bold / 카드 큰 숫자 24px Bold / 본문 14px / 라벨·캡션 12px
- 입력 필드: 라운드 8px, 1px 보더, placeholder는 연회색

**라이트 테마** (기획서 실측 기준)
- 앱 배경 #FAFAFA, 카드 흰색, 활성 요소 검정(black 버튼 + 흰 텍스트), 비활성 칩 #F5F5F5/#525252, 보더 #D4D4D4, 비활성 텍스트 #737373

**다크 테마**
- 앱 배경 #000000, 카드 #1C1C1E, 보조 배경 #2C2C2E, 액센트 #007AFF, 본문 #F2F2F7, 보조 텍스트 #8E8E93, 수익 #30D158, 손실 #FF453A
