# 화면 11. 보유 리스크 카드 (Position_RiskCard)

시뮬레이션(05)의 보유 현황 접이식 카드 확장. **현물 문법** — 매수로 생긴 보유(수량·평단·손익) 하나만 다루며 Long/Short 방향 개념은 없다. 매수 시 설정한 **손절가·목표가(화면 10)를 보유 중에 보여주고, 수정할 수 있게** 한다. 수정 이력 자체가 행동 데이터다("계획을 언제 어떻게 바꿨는가").

배경 참고: 이 단계(행동 이벤트 수집)의 나머지는 전부 화면 없는 로깅이다 — 뉴스 탭 체류, 주문 시트 열림→제출 소요시간, 주문 취소, 캔들 진행 간격 등은 기존 UI에서 조용히 기록되고 해석은 화면 12에서만 한다. 뉴스 열람 후 확신도를 다시 묻는 류의 프롬프트는 **의도적으로 없다**(측정 대상인 자연 행동이 오염됨). 이 화면이 이 단계의 유일한 신규 UI.

수치는 전부 샘플입니다.

## 유지되는 프레임 (05와 공통)

- 시뮬레이션 화면의 접이식 보유 현황 카드 (summary: 보유·미체결 수·손익 요약 → 펼치면 보유 행)
- 보유 행의 기존 정보: 수량·평단·현재 손익
- 차트에는 이미 평단 점선이 있음 (같은 시각 문법을 재사용)

## 카드 확장

보유 행 아래에 리스크 2줄 추가:

```
손절 ₩11,400 (-4.2%)          [수정]
목표 ₩13,900 (+8.1%)          [수정]
```

- 미설정이면: `손절 미설정 · [설정]` — 보유 중 사후 설정도 가능 (그것도 기록이다)
- 손절 줄은 손실색 계열, 목표 줄은 수익색 계열로 약하게 톤 구분
- **차트에 손절·목표 수평 점선** 추가 — 평단 점선과 같은 문법, 색으로 구분 (손절=빨강 계열, 목표=초록 계열, 라벨 `SL` / `TP`)

## 수정 시트

`수정`/`설정` 탭 시 작은 바텀시트:

- 제목 `손절가 수정` (또는 `목표가 설정`)
- **기존 값 → 새 값**이 나란히 보이게: `₩11,400 (-4.2%) → ₩10,800 (-9.1%)`
- 퀵 칩 + 직접 입력 (화면 10의 리스크 설정과 동일 문법)
- CTA `저장`

**중립 톤 원칙 (중요)**: 손절폭을 넓히거나 목표를 낮춰도 경고·확인 질문·죄책감 문구를 넣지 않는다. 앱은 기록만 하고 판단하지 않는다. "정말 변경하시겠어요?" 류 금지.

## 요청

세 버전을 그려주세요 (각 라이트/다크):

1. **손절·목표 설정된 보유** — 카드 펼침 + 차트 점선 3종(평단·SL·TP)이 보이는 시뮬 화면
2. **손절 미설정 보유** — 매수 시 리스크를 건너뛴 상태, `손절 미설정 · [설정]`
3. **수정 시트 열림** — 기존 값 → 새 값 비교가 보이는 상태

규격·토큰·테마는 `00-common.md` 기준. 시뮬 차트 영역의 블라인드 제약(날짜 비표기)은 `09-news.md`와 동일.
