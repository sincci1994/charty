## ❌ 미진행 항목

### 1. Play Console 앱 생성 — **사용자만 가능**
- 이름 "차티", 기본 언어 한국어, 앱/게임=**앱**, 무료
- 패키지명은 AAB에서 `io.github.sincci1994.charty`로 확정 — **첫 업로드 후 영구 변경 불가**

### 2. ⚠️ Play 앱 서명 키 지문을 assetlinks 2번 슬롯에 추가 — **가장 놓치기 쉬운 필수 단계**

업로드하면 Google이 **업로드 키가 아닌 다른 키로 재서명**한다. 지금 assetlinks에는 업로드 키 지문
하나뿐이라, **스토어에서 설치한 앱은 도메인 검증에 실패해 상단에 URL 바가 뜬다.**

```
Console → 테스트 및 출시 → 설정 → 앱 서명 → "앱 서명 키 인증서"의 SHA-256 복사
  ↓
charty-web/public/.well-known/assetlinks.json 의 sha256_cert_fingerprints 배열에 2번째로 추가
  ↓
커밋·푸시 (Vercel 배포되어야 효력 발생)
```

지문만 확보되면 이 파일 수정·커밋·푸시는 **Claude가 즉시 대행 가능**.

### 3. 등록정보 — 초안은 Claude가 작성 가능, 입력은 사용자
- [ ] 짧은 설명 (80자)
- [ ] 자세한 설명 (4000자)
- [ ] **피처 그래픽 1024×500 — 현재 레포에 없음. 새로 제작 필요**
- [ ] 폰 스크린샷 2장 이상 (Claude가 하니스로 실제 화면 캡처 가능)
- [ ] 콘텐츠 등급 설문
- [ ] 타겟 연령층 / 광고 포함 여부(현재 광고 없음)

### 4. 데이터 보안 설문 — 실제 수집 항목 (코드 기준, 초안 근거로 사용할 것)
| 데이터 | 위치 | 비고 |
|---|---|---|
| 이메일 | Supabase Auth (Google OAuth) | 계정 식별 |
| 닉네임 | `profiles.nickname` | **필수** |
| 연령대·성별 | `profiles.age_band` / `gender` | 선택, 아바타 세트용 |
| 투자 성향 | `profiles.markets` / `instruments` / `style` / `experience` | 선택 |
| 연습 기록·회고 | `records` (jsonb) | 감정·메모 포함 |
| 잔고·진행 세션 | `state` (유저당 1행) | |

전부 Supabase 저장, RLS로 본인 것만 접근, `auth.users` 삭제 시 cascade.
**금융 정보 수집 없음**(모의투자 — 실제 거래·결제 없음). 광고 ID 미사용.

### 5. ⏳ 비공개 테스트 12명 × 14일 — **최대 일정 병목 (~3주)**

## 배포 전 정리하면 좋을 것 (앱 보완 항목)

2026-08-25 작업에서 남은 미해결 — 상세는 `Archives/2026-08-25-logout-flow-typography.md`:

- **실기기 타이포 증상 미확증**: 사용자 폰은 글자 크기 기본값인데 줄 어긋남·위젯 찌부가 보인다고 함.
  하니스에서는 기본 배율(320/360/390)로 재현 실패, 1.15배 이상에서만 재현. 타이포 축소·`min-height` 전환이
  덮을 가능성은 높으나 **확증하려면 문제 화면 스크린샷 1장 필요**. 배포 전에 실기기로 확인 권장.
- **실계정 Google OAuth 왕복 미검증**: 게스트 기록이 실제 계정으로 이어받아지는 최종 왕복은
  코드 추적·네트워크 호출 순서까지만 확인(로컬은 합성 세션). 실기기 확인 필요.
- **멀티탭 로그아웃 미전파**: 한 탭에서 로그아웃해도 다른 탭은 안 비워짐 (모바일 앱 기준 의도적 보류).
- `resetAll`의 미완 리셋(`customs`/`welcomed`/`waitlistAt` 미삭제) — 기존 갭.
- 레포 루트 `icon.png`·`icon_empty.png`가 계속 untracked (8/24 아이콘 작업 산출물, 의도적일 수 있음).

## 재빌드가 필요해지면

앱 보완 중 **아이콘·이름·색·방향·packageId·권한**을 바꿨다면 AAB 재빌드가 필요하다.

1. `charty-android/twa-manifest.json`의 `appVersionName`/`appVersionCode`를 **올린다** (현재 3/3 — Play는 같은 versionCode 재업로드를 거부)
2. `bubblewrap update` → **직후 반드시** 투명 splash.png 5개와 AndroidManifest의 LauncherActivity theme 1줄 복원
   (규칙 전문: `docs/architecture/charty-android.md`의 "예외 1건/예외 2")
3. `bubblewrap build` — **키스토어 비밀번호가 필요하므로 사용자가 직접 실행해야 한다** (Claude 대행 불가)
4. 업로드 키는 그대로이므로 assetlinks 1번 슬롯은 변경 불필요

`android.keystore` **분실 = 이 packageId로 영구 업데이트 불가.** 백업 필수.

## 재검증 (다음 착수 시 먼저 실행)

```bash
cd charty-android
# AAB 지문이 assetlinks와 일치하는지
python -c "import zipfile;open('/tmp/p7','wb').write(zipfile.ZipFile('app-release-bundle.aab').read('META-INF/ANDROID.RSA'))"
openssl pkcs7 -inform DER -print_certs -in /tmp/p7 | openssl x509 -noout -fingerprint -sha256
curl -s https://charty-ruddy.vercel.app/.well-known/assetlinks.json

# 스플래시 수정이 AAB에 들어 있는지
python -c "
import zipfile; z=zipfile.ZipFile('app-release-bundle.aab')
print('Theme.Charty.Launcher' , b'Theme.Charty.Launcher' in z.read('base/resources.pb'))"

# 개인정보처리방침 살아 있는지
curl -s -o /dev/null -w '%{http_code}\n' https://charty-ruddy.vercel.app/privacy
```
