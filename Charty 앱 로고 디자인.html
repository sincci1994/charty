## 🎮 핵심 기능: 연습 ### 1. 모의투자 시뮬레이션 (Phase 1) #### 트레이딩 스타일 선택 화면 - **트레이딩 스타일 옵션** - 단타: 거래기간 1일 / 타임시리즈 5분 (*향후 추가 옵션 15분 30분) - 스윙: 거래기간 14일 / 타임시리즈 1시간 (*4시간 1일) - 장기: 거래기간 60일 / 타임시리즈 4시간 (*1일 1주) - 커스텀: 거래기간 1-365일 사용자 입력 / 타임시리즈 5분/15분/30분/1시간/4시간/1일/1주 선택 - **차트 데이터 생성 규칙** - 전체 데이터 범위: 거래기간 × 2배 - 초기 표시: 거래기간만큼 (전체의 50%) - Next 캔들로 나머지 50% 순차 공개 #### 차트 시뮬레이션 화면

포지션 선택 (LONG/SHORT) - 진입 수량 및 지정가 - 매매 이유 (검토 중: 진입 시 vs 결과 피드백 시) 2. **지정가 주문 체결 로직** - Next 캔들 진행 시 지정가 체결 여부 확인 - 체결 시 포지션 상태 변경 및 Close 탭 활성화 - 미체결 시 진입 대기 상태 유지 3. **청산 프로세스** - Close 탭에서 청산 지정가 입력 - Close Long/Close Short 지정가 주문 - 체결 시 수익/손실 계산 및 표시 4. **강제 청산 및 회고** - 트레이딩 스타일 기간 종료 시 종가 기준 강제 청산 - 결과 피드백: 매매 이유 입력 (최소 10자) + 감정 선택 + 회고 작성 - 전체 차트 및 종목명 공개 5. **중단 및 재진입 처리** - 앱 이탈 시 시뮬레이션 상태 보존 - 재진입 시 "이어하기" vs "새로 시작" 선택 제공 - 상태 복원: 현재 캔들 인덱스, 포지션, 주문 등 정확히 복원 #### 거시경제 데이터 연동 - **제공 데이터** - CPI (소비자물가지수) - PCE (개인소비지출) - VIX (변동성 지수) - 공포탐욕지수 - 채권 스프레드 - PPI (생산자물가지수) - 금리 - 주요 뉴스 헤드라인 (전쟁, 신기술, 경제, 정치) - **활용 방식** - 매매 당시 거시경제 상황 표시 - 거시경제 탭을 통한 상세 정보 제공 - 매매 판단 근거로 활용 유도 #### 감정 입력 시점 (결과 피드백 시) - **감정 선택**: 결과 피드백 시에만 ['초조', '불안', '자신감', '우울', '평범'] - **매매 이유**: 결과 피드백 시 필수 입력 (최소 10자) - **회고 작성**: 자유 텍스트 회고 작성 - **효과**: UX 단순화, 매매 종료 후 더 정확한 심리 상태 기록 ### 2. 스피드 퀴즈 (Phase 1) - **빠른 반복 훈련** - 5-10분 내 완료 - 패턴 인식 연습 - 즉시 피드백 - **간소화된 UI** - 버튼식 감정/이유 선택 - 빠른 넘어가기 - 간단한 결과 표시 ## 📚 학습 ### 1. 기술적 분석 이론 - **기초 이론** - 🔹 1. “C + 인식 곡선 (심리 + 패턴)”

  • 형태: "C" 안에 부드러운 파동 또는 지표 곡선이 들어감

  • 의미: Charty의 C + 감정 곡선, EMA 곡선, 패턴 인식 의미 통합

  • 장점: 단순하고 기억에 남음, 앱 아이콘으로도 직관적

  • 예시:

    • 원 안에 “C” + 좌우로 흐르는 곡선

    • 곡선의 위아래 감정곡선을 초록/보라처럼 감정 기반 컬러로 구분

🔹 2. “나침반 + 지표 점” 스타일

  • 형태: 원형 나침반 속에 작은 점 or 교차선

  • 의미:

    • 방향성 탐색 → 투자 생존

    • 작은 점 → “나” = 나만의 트레이딩 스타일

  • 색감: 딥 블루 배경 + Electric Purple/민트 포인트

  • 느낌: Robinhood처럼 “단순하지만 강한 상징성”

🔹 3. “지문 + 곡선” / AI 감지 패턴

  • 형태: 지문 선처럼 생긴 모양 안에 EMA 곡선

  • 의미:

    • 나만의 패턴 (지문)

    • AI가 찾아주는 습관 & 규칙

  • 스타일: 추상적이고 미래적인 느낌, Apple-style 심플

🎨 로고 스타일 제안 (Chart + Play 시각화)

🔷 1. ▶️ 버튼 + 차트 곡선

  • ▶️ 재생 버튼 안에 곡선이 흐르는 형태

  • 의미: 분석을 "플레이"하듯 반복하며 학습 → 핵심 UX 은유

  • 스타일: 미니멀, 모바일 앱 친화형

🔷 2. 차트 격자 안에서 튀어오르는 점

  • 격자 그래프에서 “점”이 튀어오르며 움직임을 형상화

  • 의미: 차트를 탐색하고 실험하며 배우는 과정

  • 역동성 강조 + 게임스러운 느낌

🔷 3. 조이스틱이나 패드 위에 있는 차트

  • 단순화된 조이스틱에 차트 선이 함께 있음

  • 의미: 차트를 조작한다 → ‘내가 주도하는 트레이딩 훈련’

  • 다소 유쾌한 톤

🔷 4. 두뇌 안의 ▶️버튼 + 파형

  • 기존 "심리/패턴" 강조 + 학습/반복의 플레이 요소 결합

  • 의미: 스스로 분석하고, 경험하며 익히는 구조

🔷 5. 문자 기반 심볼 (C + ▶️ + 곡선)

  • 예: "C" 안에 ▶️ 버튼과 곡선 파형을 겹침

  • 의미: Charty의 핵심 문자를 유지하면서 Play 요소 은유
